# 方案 B：飞特舵机路线（HD-1910）—— 本仓库当前采用的实际方案

> **状态：本仓库作者正在实践的主线方案。** 以下内容包含作者本人的实际采购决策，随进展持续更新。

## 为什么选这条路线

1. **国内现货**：官方 Dynamixel XL330-M288-T 在淘宝基本没有现货；飞特（Feetech）舵机现货多、价格低（约 ¥95-120/个零售）。
2. **飞特 HD-1910 ≠ STS3215**：HD-1910（规格书编号 `HD-1910-C001`，部分卖家/文档写作 `HD1901M`，命名不统一，下单前务必核对规格书）是专门适配 microduck 25cm 外壳尺寸的型号，不是常见的大尺寸 STS3215——STS3215 装不进原装外壳。
3. **电压更合理**：官方 XL330 被超压运行（额定3.7-6V，实际喂6.6-8.2V），而 HD-1910 额定电压本来就匹配实际工作电压，力矩还更大。
4. **执行器建模有官方支持**：飞特官方维护一套 [HD-1910 的 BAM 执行器动力学模型](https://gitee.com/ftservo/ftservo-bam)，sim2real 训练时的执行器参数标定比第三方反推 XL330 参数更有保障（这部分在 `microduck-rl` 仓库中处理）。
5. **已有完整且活跃的参考实现**：[fanhao375/microduck-replica](https://github.com/fanhao375/microduck-replica)（+ [CAD 仓库](https://github.com/fanhao375/microduck-replica-cad)）已经用这条路线跑通了站立、行走、前滚翻起身的实机验证（2026-10-24/25 实拍视频），1500+ star、每日更新，社区完整度和活跃度在调研到的所有复刻方案里最高。

## 开放问题 / 待确认

1. HD-1910 的命名在规格书、卖家标题、部分文档里写法不完全一致（`HD-1910` / `HD1901M` / `HD-1910-C001`），到货后建议拍照记录实际丝印/标签，避免后续返工时对错型号。
2. `fanhao375/microduck-replica` 的软件更新频率很高（几乎每天），建议入手时就固定一个明确标注验证过的 release/commit，装机过程中不要跟着滚动更新走，避免中途被打断。
3. 许可限制：固件镜像"仅供个人非商业复刻"，CAD 为 CC BY-NC-SA（非商业）。本仓库记录的是个人/研究用途的复刻过程，如果后续有商业化想法需要重新评估授权。
4. ToF 模块选型：本套餐选的是 VL53L8CX；`fanhao375` 主仓另有一份采购清单推荐 VL53L5CX（更小、更好装），两者固件都支持，到货后根据外壳实际适配情况再决定是否更换。
